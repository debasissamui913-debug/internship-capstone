1. **Intro (15 s):** your name and what the project is.
2. **Live site (45 s):** open the live link. Show the cards, the search and the domain filter. Search for something with no result to show the empty state.
3. **Mobile view (20 s):** open DevTools device mode and show the layout and the menu button.
4. **Apply (45 s):** submit the form empty to show errors, then fill it in and submit. Try the same email again to show the duplicate message.
5. **Backend (30 s):** open `/health` and `/api/internships` in the browser. Show the code folder in GitHub.
6. **Quality (20 s):** show `npm test` passing and the QA_REPORT.
7. **Decisions and limits (15 s):** mention SQLite on free hosting and what you would improve.

Tip: record with Xbox Game Bar (`Win + G`) or OBS, upload to YouTube as **Unlisted**, and paste the link in the README.
